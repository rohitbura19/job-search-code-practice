# Warm-up (10 min, blank page, no IDE)

1. State in one sentence the invariant of a monotonic stack (what order do the stored values keep, and why can a popped index never matter again?).
2. Write the recurrences for coin change (minimum coins) and for counting combinations. Which loop is outermost in the second one and why?
3. Token bucket vs sliding window log: which is O(1) memory per key, which is exact, which allows a burst of `capacity`?
4. Why does `SELECT ... FOR UPDATE` on two rows in arbitrary order deadlock, and what ordering rule prevents it?
