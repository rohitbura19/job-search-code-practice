# Warm-up (10 min, blank page)

1. Union-find: what do path halving and union by size each buy, and what is the amortised cost per operation? Why does `findRedundantConnection` return the LAST cycle-closing edge in input order?
2. Merge intervals: why sort by start (not end)? Which comparison decides "overlap" for closed `[1,3],[3,5]` versus half-open meetings `[0,5),[5,8)`?
3. Burst Balloons: why is "which balloon is burst LAST in (l, r)" a better subproblem than "which is burst first"? Write the recurrence.
4. `@Table(uniqueConstraints)` versus a check in the service (`existsBy...`): which one is the real guard and why do you need both?
5. Compile-time constant vs. runtime string: which of `"ja" + "va"`, `ja + "va"` (non-final local) is `==` to the literal `"java"`?
