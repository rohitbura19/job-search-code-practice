# C2. Backtracking: subsets II, generate parentheses, N-Queens count (20 min)

`c2/Backtracking.java`

1. `subsetsWithDup(int[] nums)`: all distinct subsets of an array with duplicates; each subset sorted; order free; n <= 10; do not mutate the input.
2. `generateParenthesis(n)`: all well-formed strings, n <= 12 (208 012 results, 5 s timeout).
3. `totalNQueens(n)`: count the placements; n up to 12 within the timeout. Hint: bitmasks for columns and both diagonals.
