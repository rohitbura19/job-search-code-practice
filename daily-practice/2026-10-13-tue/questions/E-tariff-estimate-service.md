## E) Notepad code-completion: Spring Boot cache + REST client + resilience + SQS (25 min)

**Task.** Complete the TODOs without an IDE. An "energy cost estimator" service: `POST /api/v1/estimates` takes a site's kWh and region, finds the tariff (cached), converts the currency through an external FX service (must not take the whole API down when FX is slow), and returns the cost. A message on SQS queue `tariff-updated` invalidates the cached tariff. Use Spring Boot 3, Java 17+.
