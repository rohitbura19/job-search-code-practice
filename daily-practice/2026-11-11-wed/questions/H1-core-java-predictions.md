# H1 - Core Java: predict the output (15 min) - `h1/H1Predictions.java`

Read `H1Snippets` (do not run it). For `s1`..`s6` write the exact string each method returns into `H1Predictions`; `H1PredictionsTest` compares with the real result.
Topics: s1 class/instance initialisation order and an overridable call from a constructor; s2 `Integer` cache, `equals` across box types, ternary typing; s3 `finally` overriding returns, masking exceptions, `break` in `finally`; s4 overload resolution (widening vs boxing vs varargs, most specific, ambiguity); s5 `hashCode` contract with a mutated key, `TreeSet` comparator as equality, access-ordered `LinkedHashMap`, `binarySearch`; s6 switch fall-through, pattern switch, `split`, `replace` vs `replaceAll`, immutable `String`.
