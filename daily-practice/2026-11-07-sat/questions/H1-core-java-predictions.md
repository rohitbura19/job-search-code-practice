# H1 - Core Java: predict the output (15 min)
`h1/H1Snippets.java` holds six snippets: initialisation order with a virtual call from a super constructor, Integer cache / string constants / interning, `finally` vs `return`/`continue`/`break`, mutable HashMap keys, overload resolution (widening vs boxing vs varargs, static types), collection views (`subList`, `unmodifiableList`, `PriorityQueue.toString`, `Arrays.asList(int[])`, access-ordered `LinkedHashMap`). Write the exact returned String of each in `H1Predictions` by hand-tracing; the test compares with the real result. Do not run the snippets first; note which ones you got wrong and name the JLS rule.
