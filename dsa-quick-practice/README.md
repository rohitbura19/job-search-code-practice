# DSA quick practice

Every DSA question from `daily-practice/`, one file per problem, grouped by pattern. No tests and no answers: each file holds a short statement, an empty method and a `main` that prints the examples with the expected output in a comment.

## How to use

- **Terminal:** `java dp/CoinChange.java` (run from this folder; no build needed).
- **IntelliJ:** right-click `dsa-quick-practice` → *Mark Directory as → Sources Root*, then use the green run arrow next to `main`.
- Timer: Easy 10 min, Medium 20 min, Hard 30 min. Answers live in `daily-practice/<day>/answers/` if you get stuck.
